# 业务变更 06 · 编辑送货单支持「带入明细」（主人纠正后定稿 2026-11-21）

> 主人需求原文：「对送货单再次编辑时，应该同样支持带入明细动态更新」。
> 主人纠正：不是给规格字段加"更新规格"按钮，而是**编辑时增加"带入明细"按钮**。
> 主人拍板：带入来源＝从报价单带入（同新建）；带入行为＝**替换现有明细**（非追加）。

## 1. 实现（纯前端，一行改动）
- `DeliveryNoteFormView.vue`：把「可选带入」卡片的 `v-if="!editingId"` 去掉，让编辑态也显示「从报价单带入」区。
- `applyQuotation()` 逻辑本就通用（整体替换 items + 更新表头客户/订单号/来源报价单），无需改动。
- 用户编辑时：打开先加载原单明细；只有主动点「带入明细」才用所选报价单的明细**替换**当前明细；不带入则沿用原明细继续手改；保存走原有 update。

## 2. 曾走弯路（已撤销）
- 第一版误解为"每行规格加更新按钮"，实现了 refreshSpec + 按钮；被主人纠正后全部撤销，改为本方案。
