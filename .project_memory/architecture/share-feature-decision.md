# 分享到微信/QQ 功能评估（2026-11-22，决定不做）

> 主人提出希望单据能分享到微信/QQ（点分享按钮自动拉起并带PDF文件）。

## 结论：技术上做不到真正的一键分享，主人决定不做

- 微信/QQ 出于安全，**未开放"第三方应用自动发送文件"的官方接口**。
- 本机实测：微信注册了 `weixin://` URL Protocol，但该协议只能打开应用/聊天窗口，**不能预填/自动发送文件**（无官方发送文件参数）。
- 联网查证（2026-11-22）未找到官方支持的桌面端文件分享 API。
- 给主人列了可行替代方案（生成PDF+打开文件夹选中文件供拖拽 / 复制路径 / 仅生成PDF），主人表示"不需要这个功能了"。

## 现状保留
- 打印预览页已有：导出 Word、导出 PDF（真正的 printToPDF）、打印。用户可自行把生成的文件发到微信/QQ。
- 未做任何代码改动。
