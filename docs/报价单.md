# 报价单

> 销售侧单据：向客户报价，记录品名规格、单价数量与报价条款；报价阶段不涉及库存，也不产生应收应付，实际出货在送货单里完成。

## 一、入口路径

左侧导航「业务单据」分组中选择「报价单」。应用使用 hash 路由，常见页面地址：

| 页面 | 路径 |
| --- | --- |
| 报价单列表 | `#/quotations` |
| 新建报价单 | `#/quotations/new` |
| 编辑报价单 | `#/quotations/:id/edit` |
| 打印预览 | `#/quotations/:id/print` |
| 打回单据列表 | `#/quotations/rejected` |

列表页右上角有「+ 新建报价单」和「打回单据」两个按钮。列表可按单号、客户、日期区间筛选，也可一键重置。

## 二、单据状态

- **草稿（DRAFT）**：新建后的初始状态，可编辑、可删除、可确认、也可直接打回。
- **已确认（CONFIRMED）**：点「确认」后的状态，表示报价已成立；不能再编辑或删除，但可以打回。
- **已打回（REJECTED）**：被打回的历史单据，移入「打回单据」列表，可预览、导出、复制。

状态流转：**草稿 → 已确认 → 已打回**；草稿也可以直接 **→ 已打回**。

> 报价单没有库存含义：确认只是状态变化，不会扣库，也不会生成应收账款。

## 三、单据字段说明

### 表头信息

| 字段 | 说明 |
| --- | --- |
| 客户（TO） | 下拉选择客户；选中后 ATTN 自动填入该客户名称（仍可手改） |
| 日期 | 报价日期，默认当天 |
| 币制 | 默认 RMB |
| ATTN（收件人） | 打印在 TO 行旁 |
| FROM（发货方） | 新建时自动带入公司基础信息里的制单人，可手改 |
| FAX | 传真号 |
| 有效期至 | 报价有效截止日期 |
| 结算及付款方式 | 单独显示在打印单据上 |
| 运输方式 | 单独显示在打印单据上 |
| 备注 / 报价条款 | 由制单人自行填写，打印时按换行显示；留空则单据不显示备注 |

### 明细行

| 字段 | 说明 |
| --- | --- |
| 关联货品 | 下拉选择「销售」类货品；选中后自动带出品名、单位、规格值，并把规格字段名存为快照 |
| 品名 | 可手工修改，必填 |
| 规格 | 点「填规格」展开，按该货品所属品类的规格字段填写；一张单可混装不同品类 |
| 单位 | 从货品带入，可改 |
| 单价 | 必填，不能为负数 |
| 数量 | 必填，不能为负数 |
| 金额 | 自动计算 = 单价 × 数量（保留两位小数），无需手填 |
| 交货日期 | 每一行的交货日期，可留空 |
| 备注 | 该行备注，打印在表格「备注」列 |

表单底部显示明细金额「合计」。

## 四、操作步骤

### 1. 新建与保存草稿

1. 列表页点「+ 新建报价单」，进入新建表单。
2. 选择客户，填写日期、币制、ATTN、FROM、FAX、有效期至、结算及付款方式、运输方式、备注报价条款。
3. 在明细区点「+ 添加一行」，选择关联货品，填单价、数量、交货日期；需要时展开填规格。
4. 点「保存草稿」。系统校验：客户必填、每行品名必填、数量和单价必填且不为负；有错在页面顶部提示。
5. 保存成功返回列表，状态为草稿。

单号由系统自动生成，规则 `QT-YYYYMMDD-四位随机数`，例如 `QT-20261123-5178`；重复时重新生成，保证唯一。

### 2. 编辑与删除

草稿行点「编辑」可修改后保存，点「删除」可删除（二次确认）。只有草稿支持编辑和删除，已确认的单据不显示这两个按钮。

### 3. 确认

在草稿行点「确认」，单据状态变为「已确认」，表示报价成立。

- 后端只改状态，**不扣减库存**，也不产生应收应付；返回结果里的 `lowStock` 恒为空。
- 实际出货请另开送货单，送货单可以从报价单带入明细，确认送货单时才扣库。

> 说明：前端列表没有单独的「确认」按钮，报价单的确认通过 API 提供；日常使用主要保存草稿并直接打印/发送给客户。

### 4. 打回

草稿或已确认的报价单都可以点「打回」，弹窗确认后状态变为「已打回」。后端仅改状态，不碰库存、不动财务。打回后的单据出现在「打回单据」列表，可预览、导出 Word/PDF、复制。

### 5. 复制

列表行（含打回单）点「复制」，生成一张新草稿：单号重新生成、日期改为当天，其余表头和明细原样带入；原单的流水引用不复制。复制后直接跳到新草稿的编辑页，可修改后再用。

### 6. 打印与导出

列表行点「打印」进入打印预览页，顶部四个按钮：

- **返回**：回到报价单列表。
- **导出 Word**：下载 `单号.docx`，纯单据内容、A4 版式。
- **导出 PDF**：桌面版真正生成 PDF 文件；浏览器下可用「打印」选「另存为 PDF」。
- **打印**：调浏览器打印对话框。

打印/导出内容同源，包括：公司名称（从公司基础信息档案读取）、标题「报 价 单」、TO / ATTN / DATE / FAX / FROM / 币制、明细表（序号、品名、规格、单位、单价、数量、交货日期、备注，不足 6 行补空行）、结算及付款方式、运输方式、按行显示的备注条款和客户填写的备注正文，以及客户与本公司两处盖章栏。规格按每行自己货品所属品类动态渲染成单行摘要，多品类混装互不干扰。

## 五、对库存与财务的影响

- 新建、编辑、复制、删除、确认、打回报价单，**都不会改变库存**，也不会产生应收应付账款。
- 报价单是纯报价记录。真正的库存减少发生在「送货单」确认时；真正的应收账款发生在「对帐单」确认时。因此报价单可放心保存、修改与打回，不影响库存账与财务账。

## 六、注意事项

1. 客户必填；单价和数量必须为非负数；金额由系统计算，不能手填。
2. 「关联货品」可留空（选「不关联」），此时该行只作文字记录。
3. 规格字段名在制单时存为快照，日后修改品类的规格名称不会改变历史单据的显示。
4. 备注条款不预置任何默认文字，完全由制单人在「备注」里自行填写；这点和订购单不同。
5. 客户名称是报价时的快照，之后修改客户档案不会回写旧单；ATTN 只在选客户时带入一次，可手改。
6. FROM 只在新建时从公司信息带入一次，编辑时不会被覆盖。
7. 送货单可从报价单带入明细，报价单确认不是出货的前置必要条件，按业务需要决定是否使用带入功能。
8. 报价单打印抬头从公司基础信息读取，若未填写公司名称，打印页显示「——」，请先到「公司基础信息」补全。
