# 订购单

> 采购侧单据：向供货商订货，草稿确认后按关联货品增加库存，并进入财务应付账款。

## 一、入口路径

在左侧导航「业务单据」分组中选择「订购单」。应用使用 hash 路由，常见页面地址如下：

| 页面 | 路径 |
| --- | --- |
| 订购单列表 | `#/purchase-orders` |
| 新建订购单 | `#/purchase-orders/new` |
| 编辑订购单 | `#/purchase-orders/:id/edit` |
| 打印预览 | `#/purchase-orders/:id/print` |
| 打回单据列表 | `#/purchase-orders/rejected` |

列表页右上角有「+ 新建订购单」和「打回单据」两个按钮。

## 二、单据状态

订购单有三种状态，列表页以彩色标签显示：

- **草稿（DRAFT）**：新建或复制后的初始状态，可编辑、可删除、可确认；此时**不影响库存**。
- **已确认（CONFIRMED）**：点了「确认」后的状态，库存已增加、应付已生成；不能再编辑或删除，只能「打回」。
- **已打回（REJECTED）**：从已确认打回来的历史单据，移入「打回单据」列表，可预览、导出、复制。

状态流转为单向：**草稿 → 已确认 → 已打回**。

## 三、单据字段说明

### 表头信息

| 字段 | 说明 |
| --- | --- |
| 供应商（TO） | 下拉选择供货商；选中后自动带出「供应商名称」 |
| 供应商名称（快照，可改） | 打印时显示的 TO 名称，可手工修改，不随供货商档案联动 |
| 订购日期 | 默认当天，格式 YYYY-MM-DD |
| 交货期 | 整单统一的一个日期，打印时显示 |
| ATTN（收件人） | 打印在 TO 行右侧 |
| FAX | 打印在表头 |
| 币制 | 默认 RMB；新建时自动带入「公司基础信息」里设置的币制 |
| FM（制单） | 新建时自动带入公司信息里的制单人 |

### 备注（打印/导出时显示）

- **备注条款**：每行一条，打印和导出 Word 时自动编号 `1．2．3．…`；留空则打印时不显示条款。
- **表尾备注**：显示在备注条款之后、盖章栏之前。

### 明细行

| 字段 | 说明 |
| --- | --- |
| 关联货品 | 下拉选择「供货」类货品；选择后自动带出品名、单位、规格，并决定确认时是否加库存 |
| 品名 | 可手工修改，必填 |
| 规格 | 点「填规格」展开，按该货品所属品类的规格字段填写；一张单可混装不同品类 |
| 单位 | 从货品带入，可改 |
| 数量 | 必填，不能为负数 |
| 单价 | 必填，不能为负数 |
| 金额 | 自动计算 = 数量 × 单价（保留两位小数），无需手填 |
| 备注 | 该行的备注，打印在表格「备注」列 |

> 说明：「关联货品」可以留空（选「不关联」），此时这一行只是文字记录，确认时不会加库存。只有关联了货品且数量大于 0 的行才会加库。

## 四、操作步骤

### 1. 新建与保存草稿

1. 在列表页点「+ 新建订购单」，进入新建表单。
2. 填写表头：至少选择供应商；日期、交货期、ATTN、FAX、币制、FM 按需填写。
3. 填写备注条款和表尾备注（可留空）。
4. 在明细区点「+ 添加一行」，选择关联货品，填写数量、单价；需要时展开规格填写。
5. 点「保存草稿」。系统会校验：供应商必填、每行品名必填、数量和单价必填且不为负；有错会在页面顶部提示。
6. 保存成功后自动返回列表，此时单据为草稿，库存不变。

系统自动生成单号，规则为 `PO-YYYYMMDD-四位随机数`，例如 `PO-20261123-3821`；若随机号重复会重新生成，保证唯一。

### 2. 编辑与删除

在列表中找到草稿单据，点「编辑」修改后保存；点「删除」可删除草稿（有二次确认）。**只有草稿能编辑和删除**，已确认的单据不显示这两个按钮。

### 3. 确认（加库）

1. 在草稿行点「确认」。
2. 系统弹窗提示「确认（将按关联货品增加库存）」，点确定。
3. 后端在事务内逐行处理：对每个关联了货品且数量大于 0 的明细，按数量增加该货品库存（库存流水原因 `PO_RECEIVE`），随后把状态改为「已确认」。
4. 加库与状态变更在同一个事务中完成，要么全部成功，要么全部不生效。

确认后，这张单的明细金额合计会出现在「财务管理 → 付款管理」的应付列表中（见第六节）。

### 4. 打回（冲销库存）

1. 在已确认的行点「打回」。
2. 系统弹窗提示「打回（将减回库存）」，点确定。
3. 后端在事务内把加库流水反向冲销（库存流水原因 `PO_REVERSE`，数量取负值），状态改为「已打回」，并删除该单关联的付款记录。
4. 冲销是幂等的：同一笔加库流水只会冲销一次，不会重复扣回。
5. 打回后的单据出现在「打回单据」列表中，可预览、导出 Word/PDF、复制。

### 5. 复制

列表行（含打回单）点「复制」，系统会生成一张新草稿：单号重新生成、订购日期改为当天、其余表头和明细原样带入，但不复制原单的库存流水引用。复制后直接进入该新草稿的编辑页，可修改后再走确认流程。

### 6. 打印与导出

列表行点「打印」进入打印预览页，页面顶部有四个按钮：

- **返回**：回到订购单列表。
- **导出 Word**：下载 `单号.docx`，内容为纯单据（不含界面按钮），A4 版式。
- **导出 PDF**：在桌面版中真正生成 PDF 文件；浏览器环境下可配合「打印」选择「另存为 PDF」。
- **打印**：调浏览器打印对话框。

打印/导出内容同源，均取自单据数据 + 公司基础信息，包括：公司名称与地址电话传真、标题「订 购 单」、TO / ATTN / DATE / FAX / FM / 币制 / 交货期、明细表（序号、品名、规格、单位、数量、备注，不足 6 行自动补空行）、编号的备注条款、表尾备注，以及供货商与本公司两处盖章栏。规格按每行自己货品所属品类动态渲染，多品类混装互不干扰。

## 五、对库存与财务的影响

- **新建/编辑/复制/删除草稿**：不影响库存，也不产生应收应付。
- **确认**：按关联货品增加库存（`PO_RECEIVE`），并在财务管理生成应付账款。应付金额 = 已确认订购单明细金额合计，付款登记关联该订购单；未付余额 = 金额 − 已登记付款。
- **打回**：冲销加库流水（`PO_REVERSE`，库存还原），删除关联付款记录；由于财务应付只统计「已确认」状态的单据，打回后该单自动从应付列表消失，相关付款统计同步失效。

库存采用流水账模型：当前库存永远是流水增量的累加，历史流水不可修改。打回不是删掉原流水，而是新增一条反向流水，可追溯。

## 六、注意事项

1. 只有关联了货品且数量大于 0 的明细行才会在确认时加库；不关联的行只作文字记录。
2. 单价和数量必须是非负数；金额由系统计算，手工改不了。
3. 确认后不能再编辑或删除；需要修改只能先打回，再复制成新草稿。
4. 供应商名称是下单时的快照，之后修改供货商档案不会回写已存在的单据。
5. 币制和 FM 只在新建时从公司基础信息带入一次，之后改动公司信息不影响旧单。
6. 打回单据只是历史记录，不能重新确认；要继续用请复制成新单。
7. 打回订购单会同步删除其付款登记记录，请留意财务数据的变化。
