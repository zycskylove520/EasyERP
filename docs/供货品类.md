# 供货品类

供货品类用于维护**供货域（采购侧）**的品类字典，并为每个品类定义一组可自定义的规格字段模板，供下属货品填写规格参数。

## 一句话定位

在采购侧先建好"有哪些品类、每个品类该记录哪些规格"，供货货品页新增货品时的规格表单就是由这里生成的。

## 入口路径

- 左侧菜单：**供货资料 → 供货品类**
- 页面路由：`#/categories/supply`（ biz=`supply` 对应供货域 SUPPLY）
- 页面标题显示为"供货品类"。它与"销售品类"是**两个独立入口、两套独立数据**，互不混用。

## 主要功能与操作步骤

### 1. 搜索与筛选

页面顶部有筛选卡片，两个输入框：

- **品类**：输入品类名称关键字，按回车或点【筛选】提交查询（模糊匹配）。
- **模块**：输入模块名称关键字，同样支持回车或点【筛选】。

点【重置】会清空两个条件并重新加载列表。列表默认按序号、id 升序显示全部供货品类。

### 2. 新增品类

1. 点右上角【+ 新增品类】，展开表单卡片，标题显示"新增品类"。
2. 填写：
   - **品类名称**：必填，留空会提示"品类名称不能为空"。同一供货域内名称不能重复，重名会被后端拒绝。
   - **模块**：必填。输入框带下拉建议（列出已有品类用过的模块名），可选旧的，也可直接输入新模块名。
   - **序号**：不可手动填写，系统按当前域最大序号 +1 自动生成（表单里显示"新增时自动"）。
3. 配置**规格字段**（见下一节），点【保存】提交；点【取消】放弃。

### 3. 配置规格字段（spec_schema）

"规格字段"决定了该品类下货品要填哪些参数，例如直径、材质、长度。表单里是一个表格，每行一个字段，列含义：

- **标识(key)**：字段的内部标识，如 `diameter`，同一品类内不能重复；填写了标识则"显示名"必填。
- **显示名**：界面上显示的中文名，如"直径"。
- **类型**：下拉选择"文本"或"数字"两种之一。数字类型在货品页会被强制为可输入的数值并做非负校验。
- **单位**：如 `MM`，可选。
- **预留**：勾选后该字段暂时不启用——先建好、前端不显示，以后要用时取消勾选即可，无需改表。
- 行尾【删】按钮移除该字段行。

点【+ 添加规格字段】新增一行。保存时系统会自动清掉"标识和显示名都为空"的行。注意：完全空行会被忽略，但只填了标识没填显示名会拦截报错。

### 4. 编辑品类

在列表某行点【编辑】，弹出同样的表单并带入原值（含规格字段）。可改名称、模块、规格字段；**序号不可改**（编辑时由系统维护）。改完点【保存】。

### 5. 删除品类

在列表某行点【删除】，确认弹窗后执行。列表的"规格字段"列会展示每个字段的"显示名 (单位)"，预留字段不显示，仅在末尾标注"+N 预留"。

删除成功后，剩余品类的序号会被自动重新编号为连续的 1..N。

## 注意事项

- **供货 / 销售分域独立**：本页只列出并管理供货域品类；同名品类在销售域可以另建一份，两边数据、规格模板互不干扰。搜索、新增、校验都限定在当前域。
- **有货品的品类不能删**：若该品类下还有货品，删除会被拒绝并提示"该品类下还有 N 个货品，请先删除或转移这些货品"，需先到"供货货品"页删除或转移货品。
- **已被使用的规格字段不能删或改标识**：编辑时若删除了某个字段、或改了它的 key，而该品类下已有货品在该 key 上存了值，保存会被拒绝，提示"规格字段 X 已被该品类的货品使用，不能删除或改名"，以防已录数据失联。闲置字段（没有货品用过）可以自由增删改名。
- **规格类型只有文本 / 数字**：后端只接受 `text` 与 `number`，其它类型会报错；标识不能为空、不能重复。
- **模块只是分组文本**：模块由使用者自由填写，用于资料归类与筛选，不额外关联其它业务。
- 规格字段采用"预留"机制，方便先搭好模板、后续逐步启用，无需改动数据表结构。
