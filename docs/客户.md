# 客户

客户用于维护销售侧的收货客户档案，包括名称、联系人、电话和地址。属于基础资料，供报价单、送货单、对帐单等销售单据引用。

## 一句话定位

在这里登记"货是卖给谁、送到哪"，记录客户联系方式与收货地址，供销售单据选用。

## 入口路径

- 左侧菜单：**基础资料 → 客户**
- 页面路由：`#/customers`
- 页面标题显示为"客户"。

## 主要功能与操作步骤

### 1. 查看列表

- 页面主体是一张表格，列依次为：名称、联系人、电话、地址、操作。
- 空的联系人、电话、地址显示为"-"。
- 列表按 id 升序排列；没有数据时显示"暂无客户"。

### 2. 新增客户

1. 点右上角【+ 新增客户】，展开"新增客户"表单卡片。
2. 填写：
   - **名称**：必填，留空提示"客户名称不能为空"。
   - **联系人**：选填。
   - **电话**：选填。
   - **地址**：选填（送货单常用）。
3. 点【保存】提交，成功后关闭表单并刷新列表；点【取消】放弃。

### 3. 编辑客户

- 列表行点【编辑】，弹出同样表单并带入原信息：名称、联系人、电话、地址。
- 修改后点【保存】。保存会把四个字段整体写回，改动即时生效；点【取消】放弃。

### 4. 删除客户

- 列表行点【删除】，确认弹窗后本地删除该客户。

### 5. 在单据中的使用

- 新建"报价单""送货单"时，表头的**客户**下拉来自本页的客户列表，且为必填（未选会提示"客户不能为空"）。
- 报价单选中客户后，会把客户名称自动填入"ATTN"（收件人）字段，仍可手动修改。
- 送货单选中客户后，会带出客户名称；若送货地址为空，还会自动填入这里登记的客户地址（已有地址则保留不覆盖）。
- "对帐单"页可按客户筛选，汇总该客户名下的送货单。

## 注意事项

- **客户是销售侧的收货方**：客户档案用于"报价单""送货单""对帐单"的客户端选择；与"供货商"（采购侧的供应商）是两套不同档案，不要混用。
- **仅名称必填**：联系人、电话、地址都可留空，后续再补。
- **编辑整体覆盖**：保存会把名称、联系人、电话、地址整体写回，未填的字段保存为空。
- **名称用于单据**：客户名称会带入报价单、送货单、对帐单的抬头，建议填写规范、便于识别的名称。
- **被引用后名称留在单据**：删除客户或改名不会自动改写历史单据中已记录的客户名称，历史单据显示的是当时保存的名称。
- **无额外字段**：本页只维护上述四项基本信息；其它如付款条件、税号等不在本模块维护。
- **页面无搜索框**：本页表格一次列出全部客户，不提供按名称筛选；数据量大时需在浏览器中查找。
- **删除不设引用拦截**：前端确认后直接删除；已被单据引用过的客户仍可被删掉，但历史单据里保存的客户名称不受影响。
- **收货信息取客户档案**：送货单选中客户时会自动带出客户名称，并在地址为空时填入这里登记的地址，请保持地址准确完整。
- 相关数据全部保存在本机用户数据目录，不上传云端，也没有账号体系。
