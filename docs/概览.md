# 概览

概览是 EasyERP 首页的数据看板：它把散落在货品、客户、库存、业务单据里的数字聚合成 4 个 KPI 卡片、6 个图表和一张负库存预警表，帮助使用者打开软件就掌握全局。

## 入口路径

- 左侧菜单「概览」分组 →「概览」，路由为 `#/overview`；应用启动时的默认首页 `/` 也会跳转到这里。
- 前端视图：`apps/web/src/views/OverviewView.vue`；后端接口：`GET /overview?months=12`。

## 页面功能与操作步骤

### 1. 选择统计时间范围

页面右上角有一个时间范围下拉框，提供三档：**近 6 个月 / 近 12 个月 / 近 24 个月**，默认为近 12 个月。

1. 打开页面，系统按当前选择（默认 12 个月）自动加载全部看板数据并绘制图表。
2. 切换下拉框后，系统会重新向后端请求数据并重绘所有图表，无需点击查询按钮。
3. 窗口大小变化时，图表会自动调整尺寸。

> 时间范围只影响「送货金额月度趋势」和「库存流水出入库趋势」这两张按月的图；KPI、饼图、单据状态、客户排行、畅出货品、负库存预警的统计口径不受该选项影响。

### 2. 阅读 4 个 KPI 卡片

| 卡片 | 显示内容 | 说明 |
| --- | --- | --- |
| 货品总数 | 货品档案数量；副标题显示品类数量 | 来自货品表和品类表的计数 |
| 客户 / 供货商 | 客户数 / 供货商数 | 两个数字用斜杠分隔 |
| 当前库存总量 | 所有货品库存数量之和（取整显示） | 副标题：有负库存时显示「⚠ N 项为负」，否则显示「无负库存」；总量为负时数字标红 |
| 本月报价 / 送货 / 对帐 | 当月三种单据数量 | 按各自单据日期所属月份统计 |

### 3. 阅读 6 个图表

1. **库存按品类分布**（环形饼图）：按品类汇总当前库存数量，扇区大小取各品类库存数量的**绝对值**（因为饼图无法表示负数）；鼠标悬停提示会显示该品类的**实际库存**（可能为负，并标注「缺货/负库存」）和占比。实际库存为负的品类，扇区强制显示为红色。库存为 0 的品类不参与展示。
2. **送货金额月度趋势**（折线图）：近 N 个月每月「已确认」送货单的明细金额之和，横轴是连续月份（没有数据的月份补 0），带平滑曲线和面积填充。
3. **单据状态分布（本月）**（堆叠柱状图）：本月创建的报价单、订购单、送货单、对帐单，按「草稿（灰）/ 已确认（绿）/ 已打回（红）」三段堆叠显示。状态按各单据表当前的状态字段统计。
4. **客户对帐金额排行**（横向柱状图）：按客户名汇总其对帐单明细金额，取金额最高的前 8 名，从大到小自上而下排列。
5. **库存流水出入库趋势**（按原因堆叠的多系列柱状图）：近 N 个月内，每种库存流水原因每月的变动量合计。不同原因用不同颜色区分（如订购入库绿色、送货扣减红色、手工调整橙色、订购冲销浅绿、送货冲销浅红等），同月各原因堆叠展示；图例可点击筛选系列。
6. **畅出货品 TOP10**（横向柱状图）：按送货单明细中的「货品名称」累计送货数量，取前 10 名从大到小排列。

### 4. 查看负库存预警

图表下方是「负库存预警」表格，列出当前库存小于 0 的货品：**货品、品类、当前库存**（红色加粗），按库存数量从小到大排列（最缺的排最前）。若没有负库存，显示「暂无负库存，一切正常。」

## 关键业务规则（数据是怎么算出来的）

1. **一次性聚合。** 整个看板由一个后端接口 `GET /overview?months=N` 返回全部数据，前端只负责渲染，不再逐个接口请求。`months` 参数会被后端限制在 1～120 之间；非法或非数字值回退为 12。
2. **库存口径与库存台账完全一致。** 当前库存总量、品类分布、负库存预警的底层算法都是「按货品对库存流水 delta 求和」，没有任何货品有多个流水就累加多次、没有流水则按 0 计算。这与「库存台账」页面显示的当前库存是同一套数字。
3. **负库存判定。** 货品流水合计 < 0 即视为负库存：既计入 KPI 里的「N 项为负」，也进入预警表格；饼图中负库存品类的扇区用绝对值绘制但标红，避免整库为负时饼图空白。
4. **本月单据数。** 「本月报价/送货/对帐」按报价单的报价日期、送货单的送货日期、对帐单的对帐日期是否落在当前自然月（`YYYY-MM`）统计，包含所有状态的单据（草稿、已确认、打回都算）。
5. **送货金额趋势。** 只统计状态为「已确认」的送货单，金额取送货单明细行金额之和；按送货日期的月份归集，并按时间范围补齐连续月份（缺月为 0）。
6. **单据状态分布。** 四类单据各自按**当前所在月**、按状态字段（`DRAFT`/`CONFIRMED`/`REJECTED`）分组计数，三类相加即为当月该类单据总数。
7. **客户排行与畅出货品。** 客户排行按客户名称分组汇总对帐单明细金额（客户名为空的排除），取 TOP 8；畅出货品按送货单明细中的货品名称累计数量（空名排除），取 TOP 10。这两个榜单不限制单据状态、也不受时间范围影响，反映的是建库以来的累计数据。
8. **库存流水趋势。** 按流水记录创建时间的月份（`created_at`）和原因分组，对各原因的 delta 求和；古老的「报价扣减/报价冲销」原因如存在于数据库，也会作为独立系列出现（图表颜色表已兼容）。

## 注意事项

- 时间范围切换只改变两张月度趋势图的月份跨度，其他卡片和榜单不会随之变化，不要误以为切换后所有数据都重算了。
- 饼图扇区大小是库存数量的绝对值，仅用于看占比；判断某品类是否缺货请看悬停提示里的「实际库存」或下方的负库存预警表。
- 负库存通常是因为送货单确认时库存不足仍被允许扣减造成的；请在业务单据页将相应送货单「打回」，系统冲销流水后预警会自动消失。
- 客户对帐排行和畅出货品榜统计的是累计数据，包含历史打回单据的明细；若需要精确的当期业绩，应到财务管理和对应单据页核对。
- 所有数据来自本机数据库，KPI 为实时计算的结果；对单据或库存做任何改动后，重新打开或切换时间范围即可看到最新数据。
- 图表使用鼠标悬停查看具体数值，图例（单据状态、流水原因）可点击显示/隐藏对应系列；宽屏下图表两列排布，窄屏自动堆叠。
- 数据加载过程中页面显示「加载中…」；如果后端请求失败，会在顶部显示红色错误信息（例如数据库连接异常），此时图表不会渲染，可稍后重新打开页面重试。

## 附：看板数据与业务模块的对应关系

了解数据来源有助于判断看板上的数字该到哪里去核对：

| 看板元素 | 数据来源 | 对应的业务页面 |
| --- | --- | --- |
| 货品总数 / 品类数 | 货品表、品类表计数 | 货品管理、品类管理 |
| 客户数 / 供货商数 | 客户表、供货商表计数 | 客户、供货商 |
| 当前库存总量 / 负库存预警 / 品类库存分布 | 库存流水按货品求和 | 库存台账 → 当前库存、库存流水 |
| 库存流水出入库趋势 | 库存流水按月份与原因汇总 | 库存台账 → 库存流水 |
| 本月报价 / 送货 / 对帐数 | 三类单据按当月日期计数 | 报价单、送货单、对帐单 |
| 送货金额趋势 / 畅出货品 TOP10 | 已确认送货单明细 | 送货单 |
| 单据状态分布 | 三类单据的状态字段（当月） | 报价单、订购单、送货单、对帐单及其「打回」页面 |
| 客户对帐金额排行 | 对帐单明细按客户汇总 | 对帐单 |

常见核对场景：

1. **看板说有负库存，但当前库存页找不到对应货品** —— 先确认是否切换了品类或货品名称有重名；两页的库存口径相同，理论上应能对应上。
2. **本月单据数比单据列表里看到的多** —— 看板统计包含草稿和已打回的单据，而单据列表默认只显示「正常」分组（草稿 + 已确认），打回的单据要到「打回」分组里查看。
3. **送货金额趋势与财务概览的收款趋势对不上** —— 两者统计对象不同：前者是已确认送货单的明细金额，后者是已确认对帐单关联的实际收款金额，属于业务链条上的不同环节。
4. **修改了库存或单据后看板数字没变** —— 看板在打开页面时一次性拉取数据，不会自动刷新；切换一次时间范围或重新进入页面即可获取最新聚合结果。
