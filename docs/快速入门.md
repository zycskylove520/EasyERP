# 快速入门

本指南面向**第一次使用 EasyERP** 的人：从安装后打开软件，到把基础资料、报价、送货、库存、财务整条流程走通一遍。所有菜单名与按钮名都取自软件界面（左侧导航 `App.vue` 与各功能页面）。软件无账号、无云服务、**无预置数据**，一切从空白开始。

> 重要约定：供货域（供货品类/货品、供货商）用于**采购侧**；销售域（销售品类/货品、客户）用于**销售侧**，两边数据独立，不要混用。文档中的"示例公司""客户A""供货商甲""货品A"都是占位示例，请替换为你自己的数据，不要照抄。

## 第 0 步：安装后第一次打开

1. 按安装包指引完成安装，首次启动会创建本机 SQLite 空库（数据放在软件的用户数据目录，不上传、不联网）。
2. 进入软件后，左侧是导航分组，右侧是功能页面。首次打开建议先看 **概览 → 数据概览**，此时各项统计都是 0，这是正常的。
3. 左侧导航的完整分组如下（后面步骤会反复用到）：

| 分组 | 菜单项 |
| --- | --- |
| 概览 | 数据概览 |
| 供货资料 | 供货品类、供货货品 |
| 销售资料 | 销售品类、销售货品 |
| 基础资料 | 供货商、客户 |
| 采购业务 | 订购单（单据列表 / 新建订购单 / 打回单据） |
| 销售业务 | 报价单、送货单、对帐单（各自含：单据列表 / 新建XX单 / 打回单据） |
| 库存管理 | 库存台账（当前库存 / 库存调整 / 库存流水） |
| 财务管理 | 财务概览、收款管理、付款管理 |
| 系统设置 | 公司信息 |

4. 带子菜单的分组（订购单、报价单、送货单、对帐单、库存台账）默认折叠，点一下父菜单展开，再点子项进入。进入某模块时系统会自动展开它。

## 第 1 步：先填公司信息

进入 **系统设置 → 公司信息**（页面标题「公司基础信息」），填写：**公司名称**（唯一必填）、默认币制（默认 `RMB`）、地址、电话、传真、手机、制单人、经营范围、送货单号前缀（留空默认 `DN`），点 **「保存」**。

为什么先做这一步：报价单/订购单/送货单/对帐单的抬头、盖章落款、制单人默认值、送货单号前缀都从这里取；先填好，后面不用逐单重复填。空库第一次进来表单是空白的，属于正常情况。

## 第 2 步：建供货品类和货品（采购侧）

1. 进入 **供货资料 → 供货品类**，点 **「+ 新增品类」**。必填：**品类名称**、**模块**（可从下拉选已有或输入新的）。按需在"规格字段"表格里点 **「+ 添加规格字段」**，填标识(key)、显示名、类型（文本/数字）、单位；不需要的字段可勾选"预留"，以后再启用。点 **「保存」**。
2. 进入 **供货资料 → 供货货品**，点 **「+ 新增货品」**。必填：**品类**（下拉）、**品名**；**单位**默认"个"可改；规格参数按所选品类的字段动态显示，按需填写。点 **「保存」**。
3. 列表支持编辑/删除。品类可被货品使用的规格字段不能删除或改标识；货品删除前注意别被未完成的单据引用。

## 第 3 步：建销售品类和货品（销售侧）

操作与第 2 步相同，只是入口换成 **销售资料 → 销售品类** 和 **销售资料 → 销售货品**，按钮同样是 **「+ 新增品类」/「+ 新增货品」**。销售域的规格模板、货品与供货域互不干扰；报价单和送货单的明细下拉里只会列出**销售货品**。

## 第 4 步：建供货商和客户

1. **基础资料 → 供货商**：点 **「+ 新增供货商」**，必填**名称**，可填联系人、电话、地址；"经营品种"支持手工输入标签（回车添加）或从供货品类下拉选择。点 **「保存」**。供货商供采购侧的订购单使用。
2. **基础资料 → 客户**：点 **「+ 新增客户」**，必填**名称**，可填联系人、电话、地址。点 **「保存」**。客户供报价单、送货单、对帐单使用；**收货地址**在新建送货单选中客户时会自动带入（此时留空才有此效果）。

## 第 5 步：走一张报价单

1. **销售业务 → 报价单 → 新建报价单**（或在「报价单 → 单据列表」页点 **「+ 新建报价单」**）。
2. 表头：选**客户（TO）**（选中后 `ATTN` 默认填客户名称）；日期默认今天；**FROM** 默认带入公司信息的"制单人"；按需填 FAX、有效期至、结算及付款方式、运输方式、备注/报价条款。
3. 明细行：点 **「+ 添加一行」**，每行选**关联货品**（自动带出品名、规格、单位），手工填**单价、数量、交货日期**；规格可点"填规格"展开该货品品类专属字段填写，一张单可混装不同品类。不选货品、手填品名也可以。
4. 点 **「保存草稿」** 后跳转回「报价单」列表。报价单**不涉及库存**，草稿状态可直接编辑、删除、打回；列表上可 **「打印」**（进入打印预览，可导出 Word / PDF、打印）、**「复制」** 生成新草稿。
5. 首次跑流程建议：保存一张报价单作练习，然后走第 6 步；打印质量可稍后再检查。

## 第 6 步：走一张送货单（关键：确认才扣库）

1. **销售业务 → 送货单 → 新建送货单**（或列表页 **「+ 新建送货单」**）。
2. 表单顶部"可选带入"：在 **「从报价单带入」** 下拉选刚建的报价单，点 **「带入明细」**，即可自动带出客户、明细和订单号码（报价单号）；带入后仍可自由修改。也可以不带入，手工填。
3. 表头：选**客户**（选中后客户名称、收货地址自动带入）、出货日期、收货地址、订单号码、整单备注；明细行填数量/单价，同样可按品类填规格。点 **「保存草稿」**。
4. 回到 **送货单 → 单据列表**：草稿状态下可 **「编辑」**、**「删除」**、**「打印」**、**「复制」**。确认要走货时点 **「确认」**，弹窗确认后状态变为"已确认"，系统按每条明细关联的货品**扣减库存**；若扣成负数，页面顶部会显示"库存不足提醒"清单，提示及时补货。
5. 已确认的送货单在列表上可以 **「打回」**：打回后状态为"已打回"，库存流水自动冲销（还回库存），单据移入 **「打回单据」** 子菜单。单号格式是 `前缀-日期-4位随机数`，前缀取公司信息里的"送货单号前缀"，留空为 `DN`。
6. 打印预览页同样有 **「导出 Word」/「导出 PDF」/「打印」** 按钮；打印内容会显示公司名称、地址、电话/手机、经营范围、制单人和金额大写。

## 第 7 步：（可选）走一张订购单，把库存补回来

1. **采购业务 → 订购单 → 新建订购单**：表头选**供货商**，填**交货期**，FM 默认取公司信息"制单人"、币制取"默认币制"；明细选**供货货品**、填数量（单价可选）。点 **「保存草稿」**。
2. 在「订购单 → 单据列表」对草稿点 **「确认」**，系统按关联货品**增加库存**；已确认的可 **「打回」**（冲销入库流水），打回单据同样在「打回单据」子菜单。订购单打印显示公司名称、地址、电话、传真和 FM。

## 第 8 步：查看库存与流水

1. **库存管理 → 库存台账 → 当前库存**：表格列出货品、品类、当前数量、单位；负数库存以红色显示。
2. 若刚起步想录入期初：**库存台账 → 库存调整**，操作选 **「设置期初」**，选货品、填期初数量、备注，点 **「提交」**。每个货品期初只能设一次。
3. 日常盘盈盘亏：同一页面操作选 **「手工调整」**，填增减数量（**负数表示扣减**），点 **「提交」**；每次调整都会记入流水。
4. **库存台账 → 库存流水**：查看每一次入库/出库/调整记录。当前库存 = 所有流水增减之和，不是单独存的数。

## 第 9 步：对帐与财务

1. **销售业务 → 对帐单 → 新建对帐单**：选客户、选**制单月份**，点 **「生成明细」**（页面按钮名），系统汇总该客户当月**已确认**的送货单明细并自动带出 FROM（制单人）和币制；确认无误后点 **「保存草稿」**。若该月没有已确认送货单，会提示"没有已确认的送货单"。
2. 到「对帐单 → 单据列表」对草稿点 **「确认」**，已确认的对帐单才会计入**应收账款**，并出现在 **财务管理 → 收款管理** 的应收列表中。对帐单可 **「打印」/「导出 Word」/「导出 PDF」**；打回后不再计入应收。
3. **财务管理 → 财务概览**：查看应收账款（未收）、应付账款（未付）、净额（应收−应付）、本月已收/已付和近 12 个月收付款趋势。应付来自**已确认的订购单**，在 **财务管理 → 付款管理** 中登记付款。
4. **收款管理**：对有余额的应收单点 **「登记收款」**，填金额、日期、方式等，点 **「保存」**；支持部分收款、多次收款。付款管理同理。

## 第 10 步：回头看概览

**概览 → 数据概览** 提供 KPI 与图表：库存按品类分布、送货金额月度趋势、单据状态分布、客户对帐金额排行、库存流水趋势、热销货品 TOP10 及负库存预警。数据都来自前面录入的单据和流水，刚上手时图表为空是正常的，随着单据确认会逐渐填充。

## 上手检查清单

- [ ] 公司信息已保存（尤其公司名称、制单人、送货单号前缀）
- [ ] 供货品类/货品、销售品类/货品各建好至少一条
- [ ] 供货商、客户各建好至少一条
- [ ] 一张报价单已保存并可打印
- [ ] 一张送货单已"确认"（库存已扣减）或已"打回"演练过冲销
- [ ] 当前库存/库存流水已查看，必要时设过期初
- [ ] （可选）一张订购单已确认入库、一张对帐单已确认并登记过收付款
