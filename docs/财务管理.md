# 财务管理

财务管理是 EasyERP 的应收应付中心：应收来自已确认的对帐单，应付来自已确认的订购单；页面只负责登记和查询收付款，未结金额由系统按单据金额减去已登记收付款实时算出。

## 入口路径

左侧菜单「财务管理」分组下有三个页面：

| 页面 | 路由（地址栏 hash） | 前端视图 |
| --- | --- | --- |
| 财务概览 | `#/finance` | FinanceOverviewView.vue |
| 收款管理 | `#/finance/receivables` | FinanceReceivableView.vue |
| 付款管理 | `#/finance/payables` | FinancePayableView.vue |

所有金额以人民币元为单位，收付款数据保存在本机数据库中。

## 一、财务概览（#/finance）

用途：一屏掌握应收应付总额、本月收付款和近 12 个月趋势。页面打开后自动加载数据，无需操作。

页面内容：

1. **四个 KPI 卡片：**
   - **应收账款（未收）**：所有已确认对帐单的未收金额之和；为负数时标红。
   - **应付账款（未付）**：所有已确认订购单的未付金额之和；大于 0 时标黄。
   - **净额（应收 − 应付）**：等于应收减应付；为负数时标红。
   - **本月已收 / 已付**：按收付款记录的「收款日期/付款日期」统计当月的合计。
2. **收付款趋势（近 12 个月）**：ECharts 双柱图，横轴为月份（从当前月往前推 11 个月，共 12 个连续月份），绿色柱是每月收款额，红色柱是每月付款额，鼠标悬停可查看具体数值。当月没有收付款的月份显示为 0。

> 该页面的趋势固定为近 12 个月，没有时间范围切换控件。

## 二、收款管理（#/finance/receivables）

用途：查看客户欠我的钱，并登记收款。

### 查看应收

页面上半部分是「应收对帐单（已确认）」表格，列有：**对帐单号、客户、日期、应收金额、已收、未收、操作**。

- 只列出状态为「已确认」的对帐单；草稿和已打回的对帐单不会出现。
- 「未收」= 应收金额 − 已收金额，大于 0 时显示为红色加粗，等于 0 时显示为绿色。
- 应收金额来自对帐单所有明细行金额之和。

### 登记收款

1. 找到要收款的对帐单行，点击右侧**登记收款**按钮（未收金额为 0 时按钮禁用）。
2. 该行下方展开表单，且「收款金额」自动预填为这笔单据的未收余额。
3. 填写各项信息：
   - **收款金额**（必填，大于 0）；
   - **日期**（必填，默认为今天）；
   - **方式**：现金 / 转账 / 微信 / 支付宝 / 银行 / 其它，默认「转账」；
   - **备注**；
   - **经手人**、**发票号**；
   - **开票状态**：未开票 / 已开票 / 不需要，默认「未开票」。
4. 点击**保存**。成功后顶部显示「已登记收款 XX 元」，表单收起，列表和记录自动刷新；点击**取消**则放弃填写。
5. 支持部分收款、多次收款：每次登记都按填的金额扣减未收金额，直到余额为 0。

### 查看与删除收款记录

页面下半部分是「收款记录」表格，列有：**单号、日期、对帐单、客户、金额、方式、经手人、发票号、开票状态、备注**，以及删除按钮。

- 单号由系统自动生成，格式为 `SK-日期-4位序号`，例如 `SK-20260115-3721`。
- 点击某行末尾的**删**按钮，在确认框中点「确定」即可删除该笔收款；删除后未收金额会自动恢复。记录按日期倒序、同日按编号倒序排列。

## 三、付款管理（#/finance/payables）

用途：查看我欠供货商的钱，并登记付款。页面结构与收款管理完全对称。

### 查看应付

表格标题为「应付订购单（已确认）」，列有：**订购单号、供应商、日期、应付金额、已付、未付、操作**。

- 只列出状态为「已确认」的订购单；草稿和已打回的订购单不会出现。
- 「未付」= 应付金额 − 已付金额，大于 0 时红色加粗，为 0 时绿色。
- 应付金额来自订购单所有明细行金额之和。

### 登记付款

1. 在目标订购单行点击**登记付款**（未付为 0 时按钮禁用）。
2. 展开的表单自动把「付款金额」预填为未付余额。
3. 填写付款金额（必填，大于 0）、日期（必填，默认今天）、方式（默认「转账」）、备注、经手人、发票号、开票状态（默认「未开票」）。
4. 点击**保存**成功提示「已登记付款 XX 元」，数据自动刷新；**取消**放弃。
5. 同样支持部分付款、多次付款。

### 查看与删除付款记录

「付款记录」表格列与收款记录一致，只是「对帐单」列换成「订购单」、「客户」换成「供应商」。系统生成的付款单号格式为 `FK-日期-4位序号`。删除操作同样需要二次确认，删除后未付金额自动恢复。

## 关键业务规则（数据是怎么算出来的）

1. **应收 = 已确认对帐单金额 − 对应已收金额。** 系统查询所有状态为 `CONFIRMED` 的对帐单，金额取该单明细行金额合计；已收金额是关联到这张对帐单、类型为「收款」的收付款记录金额之和。
2. **应付 = 已确认订购单金额 − 对应已付金额。** 口径同上，单据换成状态为 `CONFIRMED` 的订购单，收付款类型为「付款」。
3. **打回自动失效。** 判断收付款记录是否有效时，会联查其关联单据的当前状态：只有单据仍处于「已确认」才计入已收/已付、本月统计和 12 个月趋势。因此把单据打回「已打回」后，即使底层记录还在，也不会再计入应收应付统计（对帐单/订购单打回时系统还会主动删除其关联收付款记录）。重新确认后统计自动恢复（若记录未被删除）。
4. **登记收付款的四道校验：**
   - 金额必须是大于 0 的数字；
   - 日期不能为空；
   - 关联单据必须存在，且必须是「已确认」状态，否则拒绝登记；
   - 金额不能超过该单据的未结金额（允许 1 分级别的浮点误差），防止超收超付。
5. **金额只增不减地累计，余额由系统计算。** 用户不能手工修改「已收/已付」或「未收/未付」字段，只能通过新增收付款记录或删除记录来改变余额。金额保留两位小数。
6. **趋势统计口径。** 财务概览的「本月已收/已付」和 12 个月趋势按收付款记录的日期（`recordDate`）所属月份统计，并且同样只统计关联单据当前为「已确认」的记录；趋势图缺月补 0。
7. **净额 = 应收总额 − 应付总额**，只反映未结部分，不是公司利润，也不包含已结清的单据。

## 注意事项

- 草稿状态的对帐单/订购单不会出现在本模块，必须先到对应的业务单据页确认，才能登记收付款。
- 单据被打回后，关联收付款记录会被同步删除（对帐单打回删收款、订购单打回删付款）；请谨慎打回已经收款/付款的单据，如需保留记录请先确认业务处理方式。
- 收款金额默认预填未收余额，若只收部分款项请先改成实际金额再保存；金额超过未结金额会被系统拒绝。
- 删除收付款记录不可撤销，会弹出确认框；删除后余额和财务概览会立即变化。
- 开票状态、发票号、经手人、方式等只是记录信息，不参与应收应付金额计算。
- 财务概览的 12 个月趋势与本页登记记录的日期挂钩，补录历史收付款时请填写正确的业务日期，否则会统计到错误的月份。
