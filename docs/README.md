# EasyERP 使用文档

本目录按模块介绍 EasyERP 的用法，每份文档对应左侧菜单里的一个功能单元。首次使用建议先读[快速入门](快速入门.md)。

- [快速入门](快速入门.md) —— 从第一次打开软件到跑通一张完整单据

### 基础资料
- [供货品类](供货品类.md) —— 供货域品类与规格模板
- [供货货品](供货货品.md) —— 供货域货品档案
- [销售品类](销售品类.md) —— 销售域品类与规格模板
- [销售货品](销售货品.md) —— 销售域货品档案

- [客户](客户.md) —— 客户档案

- [报价单](报价单.md) —— 销售报价

- [库存台账](库存台账.md) —— 当前库存、手工调整、库存流水

## 约定

- 供货域（供货品类/货品、供货商）用于采购侧；销售域（销售品类/货品、客户）用于销售侧，两者数据相互独立。
- 单据状态：草稿可编辑，确认后生效并影响库存/财务，打回可作废并冲销影响。
- 所有数据保存在本机用户数据目录，不上传云端，也没有账号体系。
