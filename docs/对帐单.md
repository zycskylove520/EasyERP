# 对帐单

> 销售侧对帐单据：按客户和月份汇总已确认的送货单，生成对帐明细交客户核对回签；确认后进入财务应收账款，不涉及库存变动。

## 一、入口路径

左侧导航「业务单据」分组中选择「对帐单」。应用使用 hash 路由，常见页面地址：

| 页面 | 路径 |
| --- | --- |
| 对帐单列表 | `#/statements` |
| 新建对帐单 | `#/statements/new` |
| 编辑对帐单 | `#/statements/:id/edit` |
| 打印预览 | `#/statements/:id/print` |
| 打回单据列表 | `#/statements/rejected` |

列表页右上角有「+ 新建对帐单」和「打回单据」按钮。列表可按单号、客户、日期区间筛选。

## 二、单据状态

- **草稿（DRAFT）**：新建或生成后的初始状态，可编辑、删除、确认；此时不计入应收。
- **已确认（CONFIRMED）**：点「确认」后的状态，表示对帐成立、应收账款生成；不能再编辑或删除，只能「打回」。
- **已打回（REJECTED）**：打回后的历史单据，移入「打回单据」列表，可预览、导出、复制。

状态流转为单向：**草稿 → 已确认 → 已打回**。

## 三、单据字段说明

### 生成对帐单（仅新建时显示）

| 字段 | 说明 |
| --- | --- |
| 客户 | 选择要汇总的客户 |
| 制单月份 | 月份选择框（YYYY-MM），默认当前月 |
| 生成明细 | 按钮：按客户 + 月份汇总该客户当月已确认的送货单，自动填入表头和明细 |

### 表头信息

| 字段 | 说明 |
| --- | --- |
| 客户（TO） | 下拉选择；选中后带出「客户名称」和 ATTN（客户联系人） |
| 客户名称（快照，可改） | 打印显示的客户名，可手工修改 |
| 日期 | 对帐日期；由「生成明细」生成时为所选月份的第一天（如 2026-11-01） |
| ATTN | 收件人，生成时取客户档案的联系人 |
| FAX | 传真 |
| FROM | 制单人，新建时默认取公司基础信息的制单人 |
| 币制 | 默认取公司基础信息的币制，未设置则为 RMB |
| 整单备注 | 打印/导出时显示在明细表下方，按行显示；留空则不显示 |

### 明细行

| 字段 | 说明 |
| --- | --- |
| 日期 | 该行对应的出货日期，生成时取自送货单的出货日期 |
| 送货单号 | 该行来源的送货单号，生成时自动带入 |
| 品名 | 货品名称，必填 |
| 单位 | 单位 |
| 数量 | 必填，不能为负数 |
| 单价 | 必填，不能为负数 |
| 金额 | 自动计算 = 数量 × 单价，无需手填 |
| 备注 | 该行备注，生成时带入送货单明细的备注 |

表单底部显示明细金额「合计」。

## 四、操作步骤

### 1. 按客户 + 月份生成（推荐）

1. 列表页点「+ 新建对帐单」。
2. 在顶部「生成对帐单」区选择客户和制单月份。
3. 点「生成明细」。系统会查询该客户**状态为已确认、且出货日期落在所选月份**的所有送货单，把每张送货单的每条明细展开成对帐单明细行（日期、送货单号、品名、单位、数量、单价、备注）。
4. 表头自动带入：客户、客户名称、ATTN（客户联系人）、FROM（公司制单人）、币制（公司币制）、日期（月份第一天）。整单备注保留你生成前已填写的内容。
5. 生成后逐项核对、按需修改，然后点「保存草稿」。
6. 若该客户当月没有已确认的送货单，页面会提示「该客户 YYYY-MM 没有已确认的送货单」，明细保持一行空白。

> 注意：只有「已确认」的送货单会被汇总，草稿和已打回的送货单都不计入。月份按送货单的**出货日期**判断，不按对帐单日期。

### 2. 手工新建

1. 不点「生成明细」，直接在表头选择客户、填写日期与各字段。
2. 在明细区点「+ 添加一行」，手工填写日期、送货单号、品名、数量、单价等。
3. 点「保存草稿」。校验规则：客户必填、每行品名必填、数量和单价必填且不为负。

单号由系统自动生成，规则 `ST-YYYYMMDD-四位随机数`，例如 `ST-20261123-6390`；重复时重新生成。

### 3. 编辑与删除

草稿行点「编辑」可修改后保存，点「删除」可删除（二次确认）。只有草稿支持编辑和删除，已确认的单据不显示这两个按钮。

### 4. 确认（生成应收）

草稿行点「确认」，弹窗确认后状态变为「已确认」。

- 后端只改状态，**不动库存**。
- 从确认这一刻起，这张对帐单的明细金额合计计入「财务管理 → 收款管理」的应收账款；已登记收款会冲减未收余额（未收余额 = 对帐金额 − 已收金额）。

### 5. 打回

已确认行点「打回」，弹窗确认后状态变为「已打回」。后端仅改状态、不动库存，同时**删除该对帐单关联的收款记录**。由于应收列表只统计已确认状态的对帐单，打回后该单自动从应收列表消失，相关收款统计同步失效。打回单可在「打回单据」列表预览、导出、复制。

### 6. 复制

列表行（含打回单）点「复制」，生成一张新草稿：单号重新生成、日期改为当天，其余表头与明细原样带入，不复制收款记录。复制后跳到新草稿编辑页。

### 7. 打印与导出

列表行点「打印」进入打印预览页，顶部有「返回 / 导出 Word / 导出 PDF / 打印」四个按钮：

- **导出 Word**：下载 `单号.docx`，纯单据内容、A4 版式。
- **导出 PDF**：桌面版真正生成 PDF 文件；浏览器下可用「打印」选「另存为 PDF」。
- **打印**：调浏览器打印对话框。

打印/导出内容同源，包括：公司名称、标题「对 帐 单」、TO / ATTN / DATE / FAX / FROM / 币制、明细表（日期、送货单号、品名、单位、数量、单价、金额、备注，不足 6 行补空行）、整单备注、合计与人民币大写金额、客户回签与审核/作成栏，页脚还有「核对后烦请回签，TKS！！」。抬头、制单人、币制取公司基础信息与单据快照。

## 五、对库存与财务的影响

- 新建、编辑、复制、删除草稿，**不影响库存，也不产生应收**。
- **确认**：不动库存；该对帐单进入财务应收账款，可据此登记收款。
- **打回**：不动库存；删除关联收款记录，该单退出应收统计。
- 对帐单本身不改变库存，库存的增减只发生在订购单（加库）、送货单（扣库）的确认与打回环节。

应收账款只统计「已确认」状态的对帐单；因此对帐单打回后，财务概览的应收合计、收款管理的未收余额都会相应变化。

## 六、注意事项

1. 「生成明细」只汇总已确认、且出货日期在所选月份的送货单；草稿和打回单不计入。
2. 生成时对帐日期取所选月份第一天，如需其他日期可在生成后手工修改。
3. 生成时不带入送货单的 FAX（留空），ATTN 取客户档案联系人，可在表头补填。
4. 明细行的日期、送货单号只是记录来源信息，不随原送货单后续修改而联动。
5. 客户名称、ATTN、FROM、币制都是制单时的快照，之后修改客户档案或公司信息不会回写旧单。
6. 单价和数量必须为非负数；金额由系统计算，不能手填；大写金额按合计自动生成。
7. 确认后的对帐单不能编辑或删除，要修改只能打回后复制成新单。
8. 打回对帐单会同步删除其收款登记记录，请留意收款管理数据的变化。
9. 打印抬头从公司基础信息读取，若显示为空请先在「公司基础信息」补全。
