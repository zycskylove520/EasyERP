# 销售品类

销售品类用于维护**销售域（销售侧）**的品类字典，并为每个品类定义一组可自定义的规格字段模板，供下属货品填写规格参数。

## 一句话定位

在销售侧先建好"有哪些品类、每个品类该记录哪些规格"，销售货品页新增货品时的规格表单就是由这里生成的。

## 入口路径

- 左侧菜单：**销售资料 → 销售品类**
- 页面路由：`#/categories/sale`（ biz 非 `supply` 时按销售域 SALE 处理，兼容旧的 `#/categories` 路由）
- 页面标题显示为"销售品类"。它与"供货品类"是**两个独立入口、两套独立数据**，互不混用。

## 主要功能与操作步骤

### 1. 搜索与筛选

页面顶部筛选卡片有两个输入框：

- **品类**：输入品类名称关键字，按回车或点【筛选】查询（模糊匹配）。
- **模块**：输入模块名称关键字，同样支持回车或点【筛选】。

点【重置】清空条件并重新加载。列表默认按序号、id 升序显示全部销售品类。

### 2. 新增品类

1. 点右上角【+ 新增品类】，展开标题为"新增品类"的表单卡片。
2. 填写：
   - **品类名称**：必填，留空提示"品类名称不能为空"；同一销售域内名称不能重复，重名会被后端拒绝。
   - **模块**：必填，带下拉建议（列出已有品类用过的模块名），可选旧的或直接输入新的。
   - **序号**：不可手动填写，系统按当前域最大序号 +1 自动生成（表单显示"新增时自动"）。
3. 配置规格字段（见下一节），点【保存】；点【取消】放弃。

### 3. 配置规格字段（spec_schema）

规格字段决定该品类下货品要填哪些参数，例如颜色、尺码、容量。表格每行一个字段：

- **标识(key)**：内部标识，如 `color`，同品类内不能重复；填了标识则显示名必填。
- **显示名**：界面显示的中文名，如"颜色"。
- **类型**：下拉选"文本"或"数字"。数字类型在货品页做非负校验。
- **单位**：如 `MM`，可选。
- **预留**：勾选后暂时不启用——先建好、前端不显示，以后取消勾选即可，无需改表。
- 行尾【删】移除该行。

点【+ 添加规格字段】新增行。保存时自动清掉标识和显示名都为空的行；只填标识没填显示名会报错。

### 4. 编辑品类

列表行点【编辑】弹出同样表单并带入原值与规格字段。可改名称、模块、规格字段；**序号不可改**。改完点【保存】。

### 5. 删除品类

列表行点【删除】，确认后执行。列表"规格字段"列展示每个字段的"显示名 (单位)"，预留字段不显示，仅在末尾标注"+N 预留"。删除成功后剩余品类序号自动重编号为连续的 1..N。

## 注意事项

- **供货 / 销售分域独立**：本页只管理销售域品类；同名品类可在供货域另建一份，两边数据、规格模板互不干扰。搜索、新增、校验都限定在当前域。
- **有货品的品类不能删**：若该品类下还有货品，删除被拒绝并提示"该品类下还有 N 个货品，请先删除或转移这些货品"，需先到"销售货品"页删除或转移货品。
- **已被使用的规格字段不能删或改标识**：编辑时若删除字段或改了 key，而该品类下已有货品在该 key 上存了值，保存被拒绝并提示"规格字段 X 已被该品类的货品使用，不能删除或改名"，防止已录数据失联。闲置字段可自由增删改名。
- **规格类型只有文本 / 数字**：后端只接受 `text` 与 `number`，其它类型报错；标识不能为空、不能重复。
- **模块只是分组文本**：由使用者自由填写，用于资料归类与筛选。
- 规格字段的"预留"机制方便先搭模板、后续逐步启用，无需改动数据表结构。
