# 供货商

供货商用于维护采购侧的供应商档案，包括名称、联系人、电话、地址和经营品种标签。属于基础资料，供采购类单据（订购单）引用。

## 一句话定位

在这里登记"货是从哪家买的"，记录联系方式，并用经营品种标签标注各家供货商能提供哪些品类。

## 入口路径

- 左侧菜单：**基础资料 → 供货商**
- 页面路由：`#/suppliers`
- 页面标题显示为"供货商"。

## 主要功能与操作步骤

### 1. 查看列表

- 页面主体是一张表格，列依次为：名称、联系人、电话、经营品种、操作。
- 空的联系人、电话显示为"-"；经营品种以多个浅蓝色标签（chip）展示，没填显示"-"。
- 列表按 id 升序排列；没有数据时显示"暂无供货商"。

### 2. 新增供货商

1. 点右上角【+ 新增供货商】，展开"新增供货商"表单卡片。
2. 填写基本信息：
   - **名称**：必填，留空提示"供货商名称不能为空"。
   - **联系人**：选填。
   - **电话**：选填。
   - **地址**：选填。
3. 填写**经营品种**（选填，支持多个标签）：
   - 在标签输入框里输入文字后按回车，或输入框失去焦点（blur），即添加为一个标签；重复名称不会产生重复项。
   - 标签以 chip 显示，点标签右侧"×"可移除。
   - 下方【＋ 从供货品类选择…】下拉列出所有供货域品类，选中某个品类会自动把该品类名称加为标签，选完下拉自动复位。
   - 标签可自由填写，不必局限于已有品类；多个标签以中文顿号"、"分隔保存。
4. 点【保存】提交，成功后关闭表单并刷新列表；点【取消】放弃。

### 3. 编辑供货商

- 列表行点【编辑】，弹出同样表单并带入原信息：名称、联系人、电话、地址，经营品种字符串会拆回成一个个标签。
- 修改后点【保存】。保存会把所有字段整体写回，改动即时生效；点【取消】放弃。

### 4. 删除供货商

- 列表行点【删除】，确认弹窗后本地删除该供货商。

### 5. 在单据中的使用

- 新建"订购单"时，表头的**供应商**下拉来自本页的供货商列表，且为必填（未选会提示"供应商不能为空"）。
- 选中供货商后，单据会把该供货商的名称带入供应商名称字段；更换供应商时该名称会同步更新，需留意明细是否仍匹配。

## 注意事项

- **经营品种是自由文本标签**：它只是便于查看和说明的标签字段，不强制关联供货品类，也不参与库存/财务计算。从下拉选品类只是快捷录入手段，选中后同样变成普通文本标签。
- **标签格式兼容**：标签统一以中文顿号"、"连接存储；系统也能识别旧数据里用逗号（中英文）、分号分隔的多标签写法，编辑时会一并拆开。
- **标签去重与空值**：添加空内容或重复标签会被忽略；联系人、电话、地址、经营品种都可留空。
- **更新时字段整体覆盖**：保存会把名称、联系人、电话、地址、经营品种整体写回；前端表单始终提交全部字段，不会保留未改的旧值歧义。
- **用于采购侧**：供货商用于"订购单"的供应商选择；与"客户"（销售侧的收货方）是两套不同档案，不要混用。
- **删除的直接性**：供货商删除为直接删除；历史单据里已记录的名称不会被本页改动影响。
- **页面无搜索框**：本页表格一次列出全部供货商，不提供按名称筛选；数据量大时需在浏览器中查找。
- **经营品种下拉取供货域**："从供货品类选择"的下拉只列供货域品类；销售域品类不会出现在其中。
- 相关数据全部保存在本机用户数据目录，不上传云端。
