# 销售货品

销售货品用于维护**销售域（销售侧）**的货品档案。每个货品归属于一个销售品类，规格参数按该品类预设的规格字段动态填写。

## 一句话定位

在"销售品类"定义好品类与规格模板后，在这里录入具体货品（SKU）的名称、单位和规格值，供报价单、送货单等销售单据引用。

## 入口路径

- 左侧菜单：**销售资料 → 销售货品**
- 页面路由：`#/products/sale`（ biz 非 `supply` 时按销售域 SALE 处理，兼容旧的 `#/products` 路由）
- 页面标题显示为"销售货品"。
- 它与"供货货品"是**两个独立入口、两套独立数据**，不要混用。

## 主要功能与操作步骤

### 1. 按品类筛选

- 页面顶部有【按品类筛选】下拉框：默认"全部"，列出所有销售品类。
- 选中某品类后只显示该品类的货品，切换下拉会自动重新加载列表。
- 该筛选仅影响列表展示，不影响新增/编辑表单里的品类下拉（那里始终可选全部销售品类）。

### 2. 查看列表（按品类分组）

- 列表**按品类分组展示**：每个品类一个卡片，标题显示"品类名（N 个货品）"，没有货品的品类不会生成空卡片。
- 分组顺序跟随品类列表的序号（sortOrder），组内货品保持后端返回顺序（按 id）。
- 每个分组表格的列 = 品名 + 该品类自己的规格字段（显示名，带单位）+ 单位 + 操作。
- 分组只显示该品类定义的、未预留的规格字段，不会把全品类字段做成一张大宽表；某货品没填的规格显示"-"；预留字段不显示。
- 全部为空时显示"暂无货品"。

### 3. 新增货品

1. 点右上角【+ 新增货品】，展开"新增货品"表单卡片。
2. 填写基本字段：
   - **品类**：下拉选择所属销售品类（默认是列表第一个）。切换品类会清空已填规格值，因为不同品类规格字段不同。
   - **品名**：必填，留空提示"品名不能为空"。同一品类下不允许同名货品，重名会被后端拒绝并提示"货品 X 在该品类下已存在"。
   - **单位**：默认"个"，可修改。
3. 填写**规格参数**：选中品类后，系统按该品类未预留的规格字段动态生成输入框。
   - 字段名后显示单位（如"容量 (ML)"），不带单位则只显示字段名。
   - 字段类型为"数字"时输入框为 number 类型并带数字过滤（v-numeric，即时剔除字母等非法字符），保存时校验必须是数字且 ≥ 0，输入负数或有非法值会报错。
   - 字段类型为"文本"时输入框为普通文本框，任意填写。
   - 规格值按字段的 key 存入货品的 specs，表单用显式写入保证切换/编辑时响应式正确。
4. 点【保存】提交，成功后关闭表单并刷新列表；点【取消】放弃。

### 4. 编辑货品

- 列表行点【编辑】，弹出同样表单并带入原值：品类、品名、单位，以及已保存的规格值（按当前品类字段回显）。
- 可修改任意字段后点【保存】；若改了品类，货品的业务域会继承新品类（本页下拉只列销售品类）。
- 注意：编辑时**手动更改品类下拉会清空已带出的规格值**，需重新填写；这是刻意设计，避免把旧品类规格误带到新品类。

### 5. 删除货品

- 列表行点【删除】，确认弹窗后执行。
- 若该货品已被库存流水或报价单引用，删除会被后端阻止并提示"该货品已被库存或报价单引用，不能删除"。

## 注意事项

- **供货 / 销售分域独立**：本页只显示销售域货品，新增时业务域自动继承所选销售品类，无需也无法手动选择供货/销售。供货域货品请到"供货货品"页维护。
- **规格字段来自品类模板**：货品能填哪些规格、是文本还是数字、有没有单位，完全由所属品类决定。要新增/调整规格请到"销售品类"页；已被货品使用过的字段不能在品类里删除或改标识。
- **预留字段不显示**：品类里勾选"预留"的规格字段，在货品的新增表单、编辑表单和列表分组里都不会出现。
- **数字规格不能为负**：数字类规格保存时校验 ≥ 0；输入框还会即时过滤掉字母、多余小数点等非法字符。
- **切换品类会清空规格**：新增或编辑时主动更换品类下拉，之前填写/回显的规格值会被清空并提示重新填写。
- **同品类内品名唯一**：不同品类下可以存在同名货品。
- **删除有限制**：被库存或报价单引用过的货品不能删除，需先处理相关单据。
- **被销售单据引用**：报价单、送货单选货品时只列销售域货品，货品的规格值也会带入单据明细。
