# 公司信息

公司信息是一份**全系统共用的单条档案**（数据库中固定 `id = 1`），在左侧菜单 **「系统设置 → 公司信息」**（页面路径 `/company-info`，标题「公司基础信息」）中填写和维护。

报价单、订购单、送货单、对帐单的抬头与落款都自动引用这里的内容，**无需逐单重复填写**。修改保存后，之后生成的单据会使用新值；已经保存的单据中，部分字段是"制单时快照"，修改公司信息不会回溯改写旧单据。

> 软件首次运行时创建的是空库，**没有任何预置公司数据**。所有内容都需要你自己填写，怎么填完全取决于你自己的实际情况。本文档中的"示例公司""张三"等均为占位示例，不代表任何真实主体。

## 一、如何填写与保存

1. 打开左侧菜单 **系统设置 → 公司信息**，进入「公司基础信息」页面。
2. 页面加载时会自动读取已有档案；空库时表单为空白，只有「默认币制」预填 `RMB`。
3. 逐项填写下方字段。**唯一必填项是「公司名称」**，留空点保存会在页面上提示"公司名称不能为空"。其余字段都可以留空。
4. 点击右下角 **「保存」** 按钮。保存成功后页面会出现绿色提示："已保存。各单据的抬头、电话、制单人等将自动使用这里的信息。"
5. 后端使用整条替换方式保存（`INSERT ... ON CONFLICT DO UPDATE`），空库第一次保存会直接插入这条档案，不需要任何前置操作。

## 二、字段说明

| 字段（界面标签） | 是否必填 | 默认值 | 用途 |
| --- | --- | --- | --- |
| 公司名称（单据抬头/落款） | 是 | 空 | 各单据的抬头、盖章落款、打印预览顶部公司名 |
| 默认币制 | 否 | `RMB` | 报价单、订购单、对帐单新建表单的币制默认值，以及按客户月份生成对帐单时的币制 |
| 地址 | 否 | 空 | 订购单、送货单打印抬头中的"地址"行 |
| 电话 | 否 | 空 | 订购单、送货单打印抬头中的"电话"行 |
| 传真 | 否 | 空 | 订购单打印抬头中的"传真"行 |
| 手机 | 否 | 空 | 送货单打印抬头中的"手机"行（仅送货单使用） |
| 制单人（FM / FROM 默认值） | 否 | 空 | 新建报价单的 `FROM`、新建订购单的 `FM`、新建对帐单的 `FROM` 的默认值；也是送货单打印页脚"制单"和对帐单 FROM 的兜底值 |
| 经营范围（送货单显示） | 否 | 空 | 送货单打印页脚的"经营范围"行，为空时该行不显示 |
| 送货单号前缀（如填 YLD 则以 YLD 开头，留空用 DN） | 否 | 空（等效 `DN`） | 生成送货单号的字母前缀 |

字段填写示例（均为占位）：

- 公司名称：`示例公司`
- 默认币制：`RMB`
- 地址：`示例地址 1 号`
- 电话 / 传真 / 手机：`0000-00000000` / `0000-00000000` / `00000000000`
- 制单人：`制单人甲`
- 经营范围：`示例经营范围`
- 送货单号前缀：`DN`（留空即为此值）

## 三、这些信息会被哪些单据引用

### 1. 报价单（销售业务 → 报价单）

- 打印页与导出的 Word 文档顶部居中显示**公司名称**，底部盖章落款也用**公司名称**。
- 单据抬头行 `FROM`（发货方）在**新建时**默认带入**制单人**；已有单据编辑时不覆盖原值。
- 单据上的"币制"字段留空/未改时按表单默认值 `RMB` 起稿；打印时显示单据自身保存的币制。
- 注意：报价单的 `TO`、`ATTN`、`FAX` 是客户侧信息，来自制单时在表单里选择/填写的内容，不取公司档案（选中客户时 `ATTN` 默认填该客户名称）。

### 2. 订购单（采购业务 → 订购单）

- 打印页与打印数据使用公司名称、地址、电话、传真：**公司名称**显示在抬头及底部盖章处，**地址/电话/传真**显示在抬头地址行。
- `FM` 字段在新建表单中默认带入**制单人**；若单据自身 `FM` 为空，打印数据仍以**制单人**兜底。
- 币制在新建表单中默认带入**默认币制**。
- 抬头中的 `TO`（供货商）、`ATTN`、`FAX` 由制单时填写，不取公司档案。

### 3. 送货单（销售业务 → 送货单）

- 打印页与打印数据使用公司名称、地址、电话、手机：**公司名称**显示在抬头，**地址 / 电话 / 手机**显示在抬头地址行（手机为空则不显示）。
- 页脚显示**经营范围**（为空则整行不显示）和"制单：**制单人**"（为空显示 `——`）。
- **送货单号前缀**：新建送货单时系统自动生成单号，格式为 `前缀-日期-4位随机数`，例如填 `YLD` 则生成类似 `YLD-20260101-1234`；留空或只填空白字符则使用默认 `DN`。前缀中的空格和特殊符号会被剔除，生成时还会自动避开已存在的单号。
- 该前缀只在生成单号时读取一次；修改前缀只影响之后新建的送货单，已生成单号不变。

### 4. 对帐单（销售业务 → 对帐单）

- 打印页与打印数据使用**公司名称**（抬头）和**制单人**：按"客户 + 月份"生成对帐单预填数据时，`FROM` 自动带入制单人；打印时若单据自身 `FROM` 为空，也以制单人兜底。
- **默认币制**同样用于新建对帐单的币制默认值，以及按客户月份生成时的币制预填。
- 对帐单的明细来自该客户当月**已确认**的送货单，其中每行带出送货单号（其前缀即上文的公司信息设置）；草稿和已打回的送货单不计入。
- `TO`、`ATTN`、`DATE`、`FAX` 来自所选客户与制单月份/填写内容，不取公司档案。

## 四、空库首次填写提示

- 软件安装后第一次打开，数据库为空：品类、货品、供货商、客户、单据全部都没有，公司信息也是空白。**先来这里把公司信息填好再去做单据**，否则打印出来的单据抬头是 `——`、送货单号会是默认 `DN-...`。
- 页面打开后表单为空属于正常现象，不是加载失败；只有公司名称是必填项，其他信息可以后续补充。
- 「制单人」和「默认币制」建议一并填写：它们会显著减少后面填报价单、订购单、对帐单时的手工输入。
- 送货单号前缀建议在一开始就确定：先出几张送货单再改前缀，会出现同一批单据单号前缀不一致的情况。
- 所有数据只保存在本机用户数据目录，不上传云端，也没有账号体系；换电脑不会自动带来这份档案，需要在新环境重新填写。
